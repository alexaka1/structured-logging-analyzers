# SLA0004: Incorrect type is used for contextual logger

ReSharper ID: `ContextualLoggerProblem`

```csharp
class Orders
{
    public Orders(ILogger<Users> log) { }          // noncompliant
    private static readonly ILogger Log = Logger.ForContext<Users>(); // noncompliant
}

class Orders(ILogger<Users> log) { } // also analyzed (primary constructor)
```

Use the containing type as the context type.
