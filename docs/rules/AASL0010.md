# AASL0010: Context property naming

`LogContext.PushProperty` names that are compile-time constants must match
the configured convention. The diagnostic points at the name argument.

**Noncompliant**

```csharp
LogContext.PushProperty("userId", id);
```

**Compliant**

```csharp
LogContext.PushProperty("UserId", id);
```

Uses the same `dotnet_code_quality.AASL.property_naming` and
`dotnet_code_quality.AASL.ignored_properties_regex` options as AASL0009.
Scope them to this rule with `dotnet_code_quality.AASL0010.property_naming`
and `dotnet_code_quality.AASL0010.ignored_properties_regex`.

For [Semantic Conventions](https://opentelemetry.io/docs/specs/semconv/general/naming/)
attribute names (`service.name`, `http.response.status_code`):

```editorconfig
dotnet_code_quality.AASL0010.property_naming = semantic_conventions
```

**Noncompliant** (`semantic_conventions`)

```csharp
LogContext.PushProperty("OrderId", id); // suggested `order_id`
```

**Compliant** (`semantic_conventions`)

```csharp
LogContext.PushProperty("service.name", name);
LogContext.PushProperty("http.response.status_code", code);
```
