# AASL0005: Exception should be passed to the exception argument

An `Exception` (or subtype) that appears at or after the template should use
the exception parameter instead. The diagnostic points at the exception
argument.

**Noncompliant**

```csharp
Log.Error("Disk quota {Quota} MB exceeded {Exception}", quota, exception);
Log.Information(ex, "{One} {OtherException}", 1, otherEx);
```

**Compliant**

```csharp
Log.Error(exception, "Disk quota {Quota} MB exceeded", quota);
```

A correctly placed exception does not hide later exceptions that are still
template arguments. Not applied to `[LoggerMessage]`; use SYSLIB1013 and
related generator diagnostics.

Code fix: move the exception argument immediately before the message template
and, when the template is a mappable constant, remove the aligned hole. The
fix is not offered when an exception argument already sits before the template.

Microsoft logging extension calls are checked in both forms:
`logger.LogError("Failed {Error}", exception)` and
`LoggerExtensions.LogError(logger, "Failed {Error}", exception)` are
noncompliant when an exception overload is available. The reduced instance
call and the explicit static call use the same exception-placement rule.
