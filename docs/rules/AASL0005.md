# AASL0005: Exception should be passed to the exception argument

```csharp
Log.Error("Failed {Error}", exception);           // noncompliant
Log.Error(exception, "Failed {Operation}", op);   // compliant
```

Code fix: move the exception argument immediately before the message template
and, when the template is a mappable constant, remove the aligned hole.

Microsoft logging extension calls are checked in both forms:
`logger.LogError("Failed {Error}", exception)` and
`LoggerExtensions.LogError(logger, "Failed {Error}", exception)` are
noncompliant when an exception overload is available. The reduced instance
call and the explicit static call use the same exception-placement rule.
