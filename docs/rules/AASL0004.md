# AASL0004: Incorrect type is used for contextual logger

```csharp
class Orders
{
    public Orders(ILogger<Users> log) { }          // noncompliant
    private static readonly ILogger Log = Logger.ForContext<Users>(); // noncompliant
}

class Orders(ILogger<Users> log) { } // also analyzed (primary constructor)
```

Use the containing type as the context type.

Conditional-access calls such as `logger?.ForContext<Users>()` are analyzed as
well. The `ForContext<T>()` type-argument fix is offered for direct member
access calls; conditional-access diagnostics remain safe to leave unchanged.

Code fix: replace `T` with the containing type. For `ILogger<T>` declarations,
the fix also updates matching primary-constructor parameters, constructor
parameters, fields, and properties on that type. `ForContext<T>()` only
rewrites the type argument on that call.
