# AASL0001: Anonymous objects must be destructured

Anonymous objects should be captured with `@` so structured sinks serialize
their properties instead of `ToString()`. The diagnostic points at the hole.

**Noncompliant**

```csharp
Log.Error("Processed {Position}", new { X = 4, Y = 2 });
```

**Compliant**

```csharp
Log.Error("Processed {@Position}", new { X = 4, Y = 2 });
```

Not reported for positional-only templates, non-constant templates, or holes
that already use `@` or `$`.

Code fix: insert `@` into the template hole.

Not applied to Microsoft.Extensions.Logging `Log*` calls, ZLogger, or
`LoggerMessage.Define` / `DefineScope`. Those templates do not use Serilog's
`@` operator.
