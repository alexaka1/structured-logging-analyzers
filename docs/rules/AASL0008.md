# AASL0008: Prefer named properties instead of positional ones

ReSharper ID: `PositionalPropertyUsedProblem`

```csharp
Log.Information("{0}", id);     // noncompliant
Log.Information("{Id}", id);    // compliant
```

Mixed positional/named templates do not report this diagnostic.

On `[LoggerMessage]` declarations, a code fix renames `{0}` to the matching
template parameter when the remaining parameters (after the first logger,
level, and exception) line up with the positional holes.
