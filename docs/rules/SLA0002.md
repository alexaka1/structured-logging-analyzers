# SLA0002: Complex objects should be destructured

ReSharper ID: `ComplexObjectDestructuringProblem`

Complex objects whose inherited `ToString()` is `Object.ToString()` should
usually be destructured or stringified.

```csharp
Log.Information("The user is {User}", user);   // noncompliant
Log.Information("The user is {@User}", user);  // compliant
Log.Information("The user is {$User}", user);  // compliant
```

Code fix: insert `@` into the template hole.
