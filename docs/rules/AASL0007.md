# AASL0007: Message template should be compile-time constant

The template argument must be a compile-time constant. The diagnostic points
at the template expression. Other template rules still run on the same call.

**Noncompliant**

```csharp
Log.Information($"Processed {order.Id}");
Log.Information(string.Format("Processed {0}", order.Id));
```

**Compliant**

```csharp
Log.Information("Processed {OrderId}", order.Id);
```

Not applied to `[LoggerMessage]` attribute arguments. Applied to
`LoggerMessage.Define` / `DefineScope` when the format is not constant.

Code fix: convert a constant-interpolated or interpolated template into a
message template plus arguments. The default action uses the leaf identifier
(`order.Id` → `{Id}`). A second action uses qualified names (`{OrderId}`)
when that template differs from the leaf-name template. ReSharper
name-selection hotspots are not reproduced. Escaped braces in literal text
remain escaped in the generated template, preserving the runtime message.
No fix is offered when an interpolation expression has a ref-like or pointer
type because the generated object argument would not compile.
