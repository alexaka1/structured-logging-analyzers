# AASL0007: Message template should be compile-time constant

```csharp
Log.Information($"Processed {order.Id}");                 // noncompliant
Log.Information("Processed {OrderId}", order.Id);         // compliant
```

Code fix: convert a constant-interpolated or interpolated template into a
message template plus arguments. The default action uses the leaf identifier
(`order.Id` → `{Id}`). When a qualifier exists, a second action uses the
qualified name (`{OrderId}`). ReSharper name-selection hotspots are not
reproduced.
