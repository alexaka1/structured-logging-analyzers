# SLA0007: Message template should be compile-time constant

ReSharper ID: `TemplateIsNotCompileTimeConstantProblem`

```csharp
Log.Information($"Processed {order.Id}");                 // noncompliant
Log.Information("Processed {OrderId}", order.Id);         // compliant
```

Code fix: convert a constant-interpolated or interpolated template into a
message template plus arguments. Names are chosen deterministically; ReSharper
hotspots are not reproduced.
