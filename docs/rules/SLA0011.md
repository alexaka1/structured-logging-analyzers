# SLA0011: Log event messages should be fragments, not sentences

ReSharper ID: `LogMessageIsSentenceProblem`

```csharp
Log.Information("Hello {Name}.", name);     // noncompliant
Log.Information("Hello {Name}", name);      // compliant
Log.Information("Loading {Name}...", name); // compliant (ellipsis)
```

Code fix: remove the trailing period. Shared `const` messages still warn,
but the fix is withheld unless the constant is exclusive to the logging
method.

Also reported on `[LoggerMessage]` attribute strings and
`LoggerMessage.Define` / `DefineScope` format strings.
