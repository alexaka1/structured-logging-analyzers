# SLA0001: Anonymous objects must be destructured

ReSharper ID: `AnonymousObjectDestructuringProblem`

Anonymous objects should be captured with `@` so structured sinks serialize
their properties instead of `ToString()`.

```csharp
// Noncompliant
Log.Error("Processed {Position}", new { X = 4, Y = 2 });

// Compliant
Log.Error("Processed {@Position}", new { X = 4, Y = 2 });
```

Code fix: insert `@` into the template hole.
