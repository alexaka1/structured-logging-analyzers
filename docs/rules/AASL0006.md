# AASL0006: Duplicate properties in message template

ReSharper ID: `TemplateDuplicatePropertyProblem`

```csharp
Log.Information("{Id} {Id}", a, b); // noncompliant
Log.Information("{Id} {Name}", a, b); // compliant
```

Also reported on `[LoggerMessage]` when two holes use the exact same name.
Names that differ only by case are left to SYSLIB1021.
