# AASL0003: Complex objects in log context should be destructured

`LogContext.PushProperty` with exactly two arguments should pass
`destructureObjects: true` when the value needs destructuring. The diagnostic
points at the invocation.

**Noncompliant**

```csharp
class User
{
    public int Age { get; set; }
}

LogContext.PushProperty("User", new User());
```

**Compliant**

```csharp
class User
{
    public int Age { get; set; }
}

LogContext.PushProperty("User", new User(), true);
```

Not reported when an explicit `destructureObjects` argument is already present.

Code fix: add `destructureObjects: true`.

The `name`, `value`, and `destructureObjects` arguments are bound by parameter
name, so named and reordered calls are checked correctly. The fix is offered
only when the call has exactly the two required arguments.
